# Wilson Cursino app website

The root is the app directory. Each app has its own folder: Gridwise, DivIncome, Riverblast, AirbusA320, AirbusA330, Phenom300, GVTypeRating.

GitHub Pages deploys from main, repository root. Keep app-ads.txt at the root. Root privacy.html and support.html are Gridwise pages (the app was renamed from Sudoku Free) for existing App Store links. Their folder copies are under Gridwise/. Keep both copies in sync when editing policy or support content. SudokuFree/ only holds redirects to Gridwise/ so old links keep working. The source copy of these pages lives in the app repo under site/.

App Store links were verified against Apple’s developer lookup (artist 920514282). Gridwise (formerly Sudoku Free) is not in the US listing yet.

Gridwise is awaiting App Store review. Keep its Coming soon label until published, then add the verified listing URL. Other icons use Apple’s artwork URLs; Gridwise uses its project icon (assets/icons/gridwise.png).

Phenom 300 Checkride uses /Phenom300/ (marketing), /Phenom300/support.html and /Phenom300/privacy.html for its App Store URLs. The older wcursino/phenomcheckride-privacy page is superseded by /Phenom300/privacy.html.

G-V Type Rating (G450/G550) uses /GVTypeRating/ (marketing), /GVTypeRating/support.html and /GVTypeRating/privacy.html for its App Store URLs. Its icon is assets/icons/gv-type-rating.png. Keep its Coming soon label until published, then add the verified listing URL.

Airbus A330 Systems (A330 Prep / A330 Mastery) uses /AirbusA330/ (marketing), /AirbusA330/support.html and /AirbusA330/privacy.html for its App Store URLs. The privacy policy includes Apple update checks and optional support email; keep it aligned with the app.
